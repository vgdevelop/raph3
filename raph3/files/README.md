These are the database files.
actions.json - Action store.
alarms.json - Alarm store - SOON
config.json - Configuration database
devices.json - List of devices detected on the network.
sensors.json - List of sensors used within the application
status.json - SOON status control
timestamp.json - Last time saved by the device.
wifi.json - Local network connection credentials.

MANUAL CONFIGURATION - config.json

"name": the name for the device
"token": the unique ID token you want to use within the network
"exception_time": control of the general timeout
"reset_time": control of the timeout for a response
